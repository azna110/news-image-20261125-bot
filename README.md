## How it works

`main.ts` (Node 22, standard library only) copies the `entry.png` in this
repository to `/output/entry.png`. The program is fully deterministic: no
clock, no randomness, no network — two runs write byte-identical output.

Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The output image is a 1024×1024 PNG under the 1 MiB limit.
